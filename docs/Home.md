# WarmShift documentation

WarmShift is a small menu bar app for macOS. Every evening it warms your screen bit by bit using
Night Shift, the colour setting built into macOS, instead of switching it on at full strength
all at once. In the morning it puts things back.

These pages explain **how to use the app** and **what it changes on your Mac**. You don't need to
know anything about colour temperature to follow them.
